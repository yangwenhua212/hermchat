# HxSync 0.1.18（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **Edge 小艺朗读**：默认引擎对齐 Hermes `tts.provider: edge` + `zh-CN-XiaoyiNeural`；手机直连微软 Edge TTS，不再误打 Hermes 聊天地址
- **朗读引擎**：系统 / Edge 小艺 / 自定义 OpenAI 兼容 TTS / 自动（自定义→Edge→系统）
- **朗读体验**：云端 404 不再粘在顶栏；自动模式静默回退

延续 0.1.17：历史按 Agent、错误中文化、深色夜间、历史删除等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
