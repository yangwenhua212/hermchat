# HxSync 0.1.38（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **图片入口独立**：Composer 常驻图片按钮，直接进系统相册（Android 13+ 为系统照片选择器，无需存储权限）选图 → 自动压缩走 vision 通道；不用再从文档选择器里翻图片
- **聊天页去掉提示词横条**：输入框上方不再有「快捷指令」那一排提示词，聊天区更干净（设置里的快捷指令配置保留，只是不显示）

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
