# HxSync 0.1.34（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **自动朗读不再重读**：防重读标记从「进页一次」升级为「按会话作用域」——切换对话/Agent/重启收集器都会把存量历史标为已读，只有本轮新回复才开口
- **朗读图标正确回收**：任意引擎读完/失败/停止后播放态清空，气泡不再滞留「停止朗读」图标
- **Office 附件**：支持发送 Word/Excel/PPT（docx/xlsx/pptx），App 端自动抽取文字，无 vision 模型也能读懂内容
- **HEIC/HEIF 相册图**：解码走 ImageDecoder 兜底，新格式图片可导入
- **大图发送不卡 UI**：base64 编码挪后台线程

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
