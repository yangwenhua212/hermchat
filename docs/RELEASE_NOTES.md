# HxSync 0.1.20（开发预览）

**用途**：作者自用与协作者试用预览包。固化 0.1.19 之后的三关体验、剪贴板、闹钟唤起与免令牌本地模型。

## 本版重点

- **Loop 三关**：`LoopStep` 中间态；`ToolRisk` 分级确认（写操作挂起）；超步数一键切 ③ / 去添加
- **剪贴板**：`clipboard.read` 静默；`clipboard.write` 须确认
- **系统闹钟**：优先唤起系统/厂商时钟；通知回退文案标明不进系统闹钟列表
- **默认本地模型免令牌**：Qwen2.5 0.5B / TinyLlama 可直下；Gemma 仍需 HF 令牌
- **自动朗读**：仅新回复流式结束时读；回聊天页不重读

延续 0.1.19：④ Agent loop、Edge 小艺、历史按 Agent 等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
