# HxSync 0.1.27（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **表述收口**：README「已具备」——识图附件 / Loop / 本机工具；重能力在 ③
- **新工具**：`maps.search`（地图搜/导航）、`email.compose`（打开写邮件，不直发）
- **Loop 呈现**：分析中 / 执行中 / 观察中；观察后稍顿再续跑
- 修：邮件问答误触、打开地图搜被当成开应用、地图 Intent 在 Android 11+ 误判

延续 0.1.26：Loop 加固、本机记忆、首包超时、附件三期。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
