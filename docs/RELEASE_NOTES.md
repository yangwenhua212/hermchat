# HxSync 0.1.24（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **修复本地模型闪退**：进聊天/回前台不再预加载 MediaPipe；首次发消息才加载
- **按模型分级内存门槛**：TinyLlama 约需总内存 ≥5.5GB；不够则提示拒载，避免原生 OOM 杀进程
- `largeHeap` + 略降 `maxTokens`，减轻中低端机峰值

建议优先用 **Qwen2.5 0.5B**；4GB 机请勿强开 TinyLlama。

延续 0.1.23：识图附件、配置助手四档引导。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
