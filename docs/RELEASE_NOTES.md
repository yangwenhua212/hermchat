# HxSync 0.1.15（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **本地多会话历史**：新建对话不再清空旧聊；顶栏历史列表回看；满 20 条自动开新会话；换 Agent 回到该 Agent 最近会话
- **配置助手**：API Key 可整段直接粘贴，不必写 `Key:` 前缀
- **本地模型下载**：暂停与断点续传（保留 `.part` + HTTP Range）；资源库 / 配置页「暂停 / 继续」

延续 0.1.14：端侧网关手动路由、后台保活、闹钟权限、TTS、网络重试与聊天体验等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
