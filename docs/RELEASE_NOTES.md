# HxSync 0.1.17（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **历史按 Agent**：历史列表只显示当前 Agent 的会话；切换 Agent 后列表与活跃会话跟着换
- **错误中文**：网络/连接类异常（如 Unable to resolve host）统一转成用户可懂的中文短句
- **朗读**：系统 TTS 修复；设置可选系统 / 云端(`/v1/audio/speech`) / 自动回退
- **深色夜间 / 历史删除 / 模型 401**：主题「深色夜间」；历史项可删；HF 401 引导填令牌并接受许可
- **系统返回**：二级页与页内「返回」一致

延续 0.1.16：聊天主题驱动背景、相册/搜索壁纸、恢复系统默认绿等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
