# HxSync 0.1.19（开发预览）

**用途**：作者自用与协作者试用预览包。本版存档「④ 真 Agent loop」主线。

## 本版重点

- **④ Agent loop**：端侧网关 API 路径多步续跑——工具确认后把结果回灌模型继续（最多 8 步），不再只是单轮 chat
- **路由**：优先云端大脑；本地仅承接极短寒暄
- **本机工具扩展**：`url.open`、`web.search`、`share.text`（仍须确认）
- **忙态 UI**：思考中用 spinner，干活中用键盘图标（替代流式 `|` 光标）
- **Prompt**：强化 Agent 人格与多步工具说明

延续 0.1.18：Edge 小艺朗读、历史按 Agent、错误中文化等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
