# HxSync 0.1.40（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **不再预填作者的 HxMV 实例地址**（开源版重要调整）：地址默认留空，谁装谁填自己的实例（本机 `http://127.0.0.1:8668` 或自己部署的域名）；没填就直接提示该填什么，不再去连一个别人的服务器
- **连接排障更省事**：「保存并检测」改为**短超时探测**（点一下立刻有反应，不再干等几十秒）+ 失败自动重试一次 + 状态行常驻**「重试」**按钮；失败原因带真实关键词（如 `stream was reset`），不再只报「连不上」
- **参考图可一次选多张**：选多张 → 弹窗给每张起名（默认取文件名）→ 逐张上传并报进度
- 服务对话框补 placeholder 说明（地址示例 / 令牌可留空）

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。

## 历史版本
