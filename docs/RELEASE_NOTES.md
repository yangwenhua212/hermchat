# HxSync 0.1.22（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **聊天壁纸**：自定义图片只铺消息列表；顶栏与输入区仍用主题渐变

延续 0.1.21：本地优先解析实验、Loop 三关、剪贴板、系统闹钟唤起、免令牌本地模型等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
