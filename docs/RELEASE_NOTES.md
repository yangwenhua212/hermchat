# HxSync 0.1.16（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **聊天外观**：主题色同时驱动气泡与整页背景（系统默认绿 / 浅雾绿 / 浅天蓝 / 浅青 / 浅灰白 / 浅杏 / 墨黑）
- **聊天背景图**：相册选图；精选壁纸下载；关键词搜索（精选 + Wikimedia）；可清除图片 / 一键恢复系统默认绿

延续 0.1.15：多会话历史、配置助手裸 Key、本地模型暂停续传等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
