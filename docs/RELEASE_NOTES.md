# HxSync 0.1.14（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **④ 端侧网关路由**：设置 → 端侧网关 → **自动** / **优先本地** / **优先云端**；手选本地不因弱回复擅自改走 API
- **README**：聚合客户端定位、四档与资源库说明；设备指纹 / 服务商市场标为远期未实现

延续 0.1.13：资源库、模型选用、唤醒增强、TTS、端侧网关混合路由与故障转移等。

### 体验优化（0.1.14 后续提交）

- **网络健壮性**：OpenAI 兼容请求自动重试（最多 2 次），网络抖动自动恢复；4xx 客户端错误不重试、快速报错；共享 OkHttpClient 减少连接开销
- **TTS 朗读**：中文语音包检测与缺失提示（引导下载）、音频焦点管理（不打断音乐/其他应用）、朗读失败原因可见
- **聊天体验**：本地网关通道边生成边流式显示（不用等全部生成完）；滚动/语音状态/TTS 的 LaunchedEffect 合并，减少重组；流式渲染用轻量 String Flow，token 更新更流畅

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
