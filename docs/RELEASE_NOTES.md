# HxSync 0.1.25（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **④ 路由**：默认云端；「使用本地模型」须风险确认；可只配 API 或只配本地
- **手动配置**：类型列表不再单列 Hermes（助手/扫码/旧档仍可用）
- **附件**：PDF 按「PDF · 文件名」展示；真图才缩略图（首页仍可识图）
- TinyLlama 标明英文为主；对其改用英文 system prompt
- UI 约定：不堆冗余入口（见 `docs/UI.md`）

延续 0.1.24：本地模型懒加载，修进聊天闪退。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
