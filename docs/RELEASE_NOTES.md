# HxSync 0.1.13（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **资源库**：管理 Agent、本地模型（路径 / 下载 / 删除）、HF 搜索 litert `.task` 并下载
- **选用模型**：资源库「选用到当前」；本地 / 端侧网关配置页可选目录中的模型（网关 API 模型与本地兜底分离）
- **唤醒**：自定义唤醒词、聊天页内免喊词直说、开机恢复监听开关

延续 0.1.12：TTS、设置树、端侧网关与故障转移等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
