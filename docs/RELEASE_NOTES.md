# HxSync 0.1.23（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **识图 / 附件**：Composer 可发图片与 txt/md/csv/json；PDF 首页当图；文本注入各档可用
- **配置助手四档**：开场列出 ③/④/②/① 示例话术；本地可一键确认；端侧网关不再误探局域网

延续 0.1.22：壁纸仅消息区等。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
