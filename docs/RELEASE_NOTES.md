# HxSync 0.1.14（开发预览）

**用途**：作者自用与协作者试用预览包。

## 本版重点

- **④ 端侧网关路由**：设置 → 端侧网关 → **自动** / **优先本地** / **优先云端**；手选本地不因弱回复擅自改走 API
- **README**：聚合客户端定位、四档与资源库说明；设备指纹 / 服务商市场标为远期未实现

延续 0.1.13：资源库、模型选用、唤醒增强、TTS、端侧网关混合路由与故障转移等。

### 体验优化（0.1.14 后续）

- **网络健壮性**：OpenAI 兼容请求开流前最多重试至 2 次；**已吐字不重试**；4xx / 未知主机不重试；不因重试换 Hermes Session；共享 OkHttpClient
- **TTS 朗读**：中文语音包检测与缺失提示；正确申请/释放 `AudioFocusRequest`；失败原因可在聊天页提示
- **聊天体验**：流式用轻量 String Flow；④ **优先本地**边生成边显示；**自动**模式 escalate 前缓冲，避免弱回复与 API 叠字
- **本机闹钟**：确认前要通知权限；缺精确闹钟会引导设置（不再假成功）；跨日时间走本机提醒；话术支持「提醒我明天×点」
- **后台连接**：连接提到 Application；WebSocket/Hermes 显示「保持连接」通知；退出聊天页 / 回桌面不故意断线（划掉多任务仍会杀进程）

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
