# HxSync 0.1.21（开发预览）

**用途**：作者自用与协作者试用预览包。在 0.1.20 之上增加实验「本地优先解析」。

## 本版重点

- **本地优先解析（实验）**：设置 → 端侧网关；开前知情弹窗；首轮本地试跑 tool JSON，失败顶栏「已改用云端」并走 API；续跑仍强制云端
- 默认仍云脑 Loop；规则闹钟/日历兜底不变

延续 0.1.20：Loop 三关、剪贴板、系统闹钟唤起、免令牌本地模型、自动朗读不重读。

## 安装

```bash
./gradlew :app:assembleRelease
```

同 release 签名可直接覆盖；debug → release 须先卸载。
