# 本地运行时 / 本地模型（Phase B）

> 状态：**规划中，未实现。**  
> 产品总述见 [PRODUCT.md](PRODUCT.md)。品牌表述 **B**：HxSync 是通用口袋客户端；本地运行时兼容开放协议（含 Hermes 一类），**不宣称「仅 Hermes 官方 App」**。

## 目标

让第三种模式落地：**本地运行时**——推理与（可选）轻量 Agent 逻辑在手机内执行，可：

- 加载本机开源小模型（隐私 / 弱网）  
- 或在本地编排层上再转发到 DeepSeek 等 API（混合）  

Phase A 的「远程 Agent」「直连 API」保持不变；本地模式是**增量**，不是替代。

## 非目标（Phase B 仍不做）

- 在手机上完整复刻桌面 Python Hermes 的全部插件生态  
- 替代 eraherm-memory（记忆仍外置可挂）  
- 强制用户必须用某一品牌模型或运行时  

## 建议技术方向（待立项）

| 层 | 候选 | 说明 |
|----|------|------|
| 推理 | llama.cpp / ExecuTorch / ONNX Runtime | 优先成熟 Android 绑定与量化模型 |
| 编排 | 精简 Kotlin「兼容运行时」 | 对话状态、工具确认复用现有 `PhoneTool` |
| 协议 | 对内统一成与现网一致的消息流 | UI 仍只认一种流式出口，便于三模式切换 |
| 分发 | 模型按需下载到 `filesDir` | 体积、校验、删除与流量提示要做产品设计 |

## 配置构想（UI）

新增类型例如「本地」：

1. 选择已下载模型，或「仅本地编排 + 远程 API」  
2. 无需填局域网 IP  
3. 与远程 / 直连配置并列，顶栏切换  

文案保持简洁，遵守 [UI.md](UI.md)（无堆砌说明小字）。

## 验收草案

- [ ] 无网可对已下载小模型完成一轮问答  
- [ ] 本地模式下本机工具确认流仍可用  
- [ ] 与远程 / 直连配置可同时保存并切换  
- [ ] 未下载模型时有明确主操作（下载），无长篇备注刷屏
