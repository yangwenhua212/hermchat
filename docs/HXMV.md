# HxMV 内容生产接入

HxSync 的「HxMV 内容生产」页：把 HxMV（自主内容生产闭环 Agent）当远端服务或手机本机服务来用。
入口：设置 → **HxMV 内容生产**。

## 第一次要做的两件事

**1. 填地址 + 令牌**（HxMV 实例默认要令牌，否则只显示「需要令牌」）
右上角 **服务** → 填**你自己的** HxMV 实例地址（本机 Termux：`http://127.0.0.1:8668`；自己部署的域名同理），
再填令牌（实例没设可留空）→ **保存并检测**。
状态会变成「已连接 <你的地址> · HxMV/0.6」。

> App **不预填任何实例地址**：HxSync 是开源软件，预填作者的实例等于让所有下载的人都用作者的服务器。
> 地址和令牌都填你自己的。

令牌在部署 HxMV 的机器上：`~/.hxmv/panel.env` 里的 `HXMV_WEB_TOKEN=`。

**2. 不需要大模型 Key 也能跑**
后端「本地真渲染」「模拟世界」开箱即用（不需要任何 API Key）。
「智谱真视频」要智谱的 Key（免费额度）：在 HxMV 机器上执行
`python3 -m hxmv --set-key zhipu <KEY>`。没有 Key 时会明确显示该后端不可用。

## 两种跑法（同一套接口，只有地址不同）

| 模式 | 地址 | 说明 |
|---|---|---|
| 远端 | 你自己部署的 HxMV 域名（如 `https://你的域名`） | 服务器出片；手机只管提交和看片 |
| 手机本机 | `http://127.0.0.1:8668` | 手机自己跑（Termux 里跑 HxMV），不依赖服务器 |

## 手机部署（页面里三步）

| 步骤 | 做什么 |
|---|---|
| ① 装 Termux | 手机上装 Termux（应用商店或 GitHub Releases）；装完回页面会自动变成「Termux 已装好」 |
| ② 复制一键安装命令 | 复制的命令粘到 Termux 里回车，脚本会装好 HxMV 并启动在本机 8668 |
| ③ 检测本机 HxMV | 探测 `127.0.0.1:8668`，探到就自动把地址切到本机 |

> 安装包不能被静默安装、命令也不能代你粘贴，所以这三步必须点一下——不是没做，是安卓不让。

## 用起来

HxMV 页现在是**两个 Tab 的 App 式入口页**（对齐市面 AI 视频 App）：

- **创作**（默认）：hero + 功能胶囊（沉浸式短片 / 输入灵感 / 照片跟我动 / 一镜到底 / 角色一致性 / 续做同一部）
  + 底部大输入框「输入灵感，一键成片」。点「一镜到底」「续做同一部」这类胶囊会**直接预填灵感**，改两字就能发
- **作品**：一次生产一条（状态 / 时间 / 删掉），空的时候提示去创作

发出去或点「开工」才进**会话流**（「← 创作」可返回）：

0. **说一句**：在聊天框说想做什么（如「一只柯基在雪地里打滚，8 秒」）→ 它回你一句 + 给出**可执行的目标**
   → 点「**开工**」**直接开跑**（一次点击，不再「先填目标再点开始」）。空会话时下面有三句起手示例，点一下直接发。
   想改需求继续说（「太暗了，换成清晨」），它会基于上一条改——没点开工之前**不花钱、不落档**
1. **本次生产就长在对话下面**：分镜 · 角色 · 场景 · 镜头 · 成片 逐行状态和实测指标、成品、删片按钮都在这一条里
2. **成品**：播放（系统播放器）/ 保存（进相册 `Movies/HxSync`）
3. **不满意就删**：点「不满意，删掉这条」→ 删掉这次跑的所有片子，并撤销它在项目档案里的登记（角色/场景/镜头/集数），被否掉的片不会再当"设定"影响后面。满意就什么都不用做
4. 聊天框下面一条工具：**后端档位**（智谱真视频/本地渲染/…）+ **项目名**（可留空；填了续做同项目不重画已有画面）

## 喂参考图（角色 / 场景）

图生视频的第一帧就是参考图——**第一帧基本决定画面里的场景**。所以要什么场景，就选一张「在那个场景里的角色照」当角色参考图。

| 步骤 | 做什么 |
|---|---|
| ① | 填「项目」（续做同一个项目才会复用已生成的画面） |
| ② | 参考图 → 选**角色**或**场景** → 填名字（镜头里用的角色名/场景名，如 `柯基`） |
| ③ | **选图上传** → 缩略图网格里出现即可用 |

- **一次选多张**：选图时可以多选——多张会弹出「给这 N 张起名」（默认 `名字1`、`名字2`…），确认后逐张上传并报进度；单张仍直接上传
- **看大图**：点缩略图打开大图（看清用的是哪张）
- **删除**：在大图里点「删除」（不放在网格上，避免误删）
- 角色设定表可以直接传：服务端会自动裁上部主视觉当第一帧（不会把整张版式画进视频）

## 接口配置（Key / 档位）

右上角 **配置**：

| 项 | 说明 |
|---|---|
| 智谱 Key | 只显示脱敏串；粘贴新 Key 保存即生效 |
| 视频模型 | 免费档 / 付费档（按次计费，档位上有价格） |
| 视觉评审 | 判「角色像不像、符不符合分镜」用的模型；免费档即可 |

**保存后立即生效，不用重启 HxMV 实例。**

## 排查

| 现象 | 原因 |
|---|---|
| 状态显示「需要令牌」 | 令牌没填：右上角 **服务** 填；或实例上 `HXMV_WEB_TOKEN` 被改过 |
| 状态显示「令牌不对」 | 令牌填错 |
| 状态显示「连不上 HxMV」 | 地址不对/网络不通（实例要不要令牌都能探测，所以这个是真的连不上） |
| 「智谱真视频」跑不动 | 实例上没配智谱 Key |
| ③ 检测不到本机 | Termux 里 HxMV 没起来；回 Termux 看脚本输出 |

接口契约见 HxMV 仓库 `docs/CLIENT.md`。
