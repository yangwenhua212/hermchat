# UI / 文案技术规范

所有 HxSync 界面与相关 Compose 改动**必须**遵守本节。避免每次改完再靠人工要求「去掉小字」。

## 原则

1. **干净优先**：主界面、设置页、配置步进只保留**可操作的主文案**（标题、按钮、字段 label、必要状态）。  
2. **禁止说明型小字**：不要在选项卡片、列表项、输入框下方堆「备注 / hint / 灰色说明句」。  
3. **状态一句话**：成功/失败用短状态即可（如「测连成功」「找不到服务器」），不要附带技术细节（如 `Unable to resolve host`、`eventId=`、长错误栈）。网络/系统异常经 `UserFacingError` 转成中文短句再展示。  
4. **长说明放文档**：协议、踩坑、接入教程写在 `docs/`，不要塞进 App UI。  
5. **错误可消失**：短暂提示（如无语音引擎）应自动消失或可点掉，不要长期占聊天顶栏。  
6. **不堆冗余入口（精简高效）**：同一能力不要在 UI 里再开一条几乎重复的路径占位。能合并就合并；细分协议/品牌用配置助手、扫码或已存档案承载，**不要**为每种变体多占一行类型/开关。  
   - 反例：手动配置同时列「Hermes」与「HTTP 兼容」（同属 HTTP 大脑，占双份选择位）——已改为列表不单列 Hermes。  
   - 正例：四档能力（①②③④）各一条清晰入口；③ 内 WebSocket vs Hermes HTTP 用助手/扫码区分，不重复铺开。

## 允许保留

- 品牌名、Agent 显示名、按钮文字、TextField 的 `label` / 短 `placeholder`  
- 连接状态「已连接 / 未连接」  
- 确认卡标题 + 一行摘要（工具确认所必需）  
- 无障碍 `contentDescription`（不显示在视觉主文案里）  

## 聊天页体验

- **顶栏状态 / 系统气泡**：最多一行（超出省略）；勿把整段回复挂在顶栏  
- **④ Loop 中间态**：`LoopStep` 一行短句上屏，前缀区分 **分析中 / 执行中 / 观察中**；观察阶段稍顿再续跑；勿超过约 1s 黑盒；确认卡出现时收起中间态避免叠文案  
- **本机工具确认**：写操作弹确认卡；取消即结束本轮 Loop；勿在确认卡外再堆说教灰字  
- **识图 / 附件**：Composer 旁附件入口；真图可缩略图并可点大图；PDF/文本用「PDF · 名」/「文件 · 名」；不支持通道一行短状态，勿堆灰字教程
- **思考中**用机器人侧 `TypingBubble` 转圈；**吐字/执行中**气泡末尾键盘图标（不再用 `|` 光标）；发送钮不要转圈锁死输入框；等待回复时仍可打字改草稿  
- **超步数**：顶栏一行短提示 + 按钮「切换到 xxx」或「去添加」，勿长篇说明  
- **搜索 Key**：设置 → 搜索 仅两个 Key 字段；无灰字教程；行为见 [REMOTE_BRAIN_LOCAL_TOOLS.md](REMOTE_BRAIN_LOCAL_TOOLS.md)  

- **外观**：主题色同时影响气泡与聊天区背景渐变（含深色夜间整 App Material）；自定义图片壁纸**只铺消息列表**，顶栏与输入区仍用主题渐变；半透明遮罩保证可读；设置 → 外观可恢复系统默认绿
- **系统返回**：二级页 / 子文件夹与页内「返回」一致；聊天首页系统返回仍退出 App  
- **朗读失败**：短状态提示即可；Edge/自动失败可回退系统；设置 → 朗读可选 Edge 小艺 / 自定义 TTS（Hermes 对齐说明见 CONNECT_AGENTS，不堆灰字）  
- **自动朗读**：开自动后只对 **AI 本轮刚生成** 的回复边出字边按句读（或非流式整段落盘读一次）；离开再进聊天、回看历史**不会**再自动读；关掉自动时仍可点气泡喇叭整段读

## 禁止示例

- 「电脑终端出二维码时，可直接扫码…」  
- 选项下「WebSocket 端点（模拟器访问本机用 10.0.2.2）」  
- 「需要你确认后才会操作手机。」类说教句（确认卡有标题+摘要即可）  
- 系统气泡里的调试字段  

## 实现检查清单

改 UI 或加设置项时自问：

- [ ] 删掉该行灰字后，用户仍知道点哪里吗？能则删。  
- [ ] 是否把教程写进了 `docs/` 而不是 Screen？  
- [ ] 新增枚举选项是否只有 `label`、没有附带 `hint` 展示？  
- [ ] 新选项/类型是否与已有入口能力重叠？重叠则合并或藏进助手/导入，勿多占一位。
