# 真机日记 / 验收（自用）

对照「自己用得爽」：每天卡在哪、多哪一步，记在文末日记。自动化测试次要。

最短上手：[README.md](../README.md) · 连 Agent：[CONNECT_AGENTS.md](CONNECT_AGENTS.md) · 远程大脑：[REMOTE_BRAIN_LOCAL_TOOLS.md](REMOTE_BRAIN_LOCAL_TOOLS.md)

环境：自己的 Android 真机；电脑与手机同一 Wi‑Fi（连电脑 Agent 时）。

## 检查清单（随手勾）

### 安装与配置

- [ ] Release APK 能装上（同签名覆盖；debug→release 先卸）
- [ ] **添加 Agent** 能进配置助手，不会闪回聊天
- [ ] 「连电脑上的助手」或手填 `ws://` 能测连进聊天
- [ ] **端侧网关**：配 DeepSeek +（可选）下载本地模型；短句走本地、长问走 API；改闹钟出确认卡
- [ ] 纯 HTTP 兼容：只聊天、无本机工具确认（②）
- [ ] **资源库**：设置 / Agent 下拉可进；能看到模型目录路径；已装可删、可「选用到当前」
- [ ] 本地 / 网关配置页可选目录中的模型（网关 API 名与本地兜底分开）

### 对话与工具（主线 ③）

- [ ] 流式回复跟手；「新建对话」能救慢会话；历史列表能回看旧聊且不丢
- [ ] 助手气泡喇叭可朗读；设置「朗读回复」可自动读完
- [ ] 本机工具确认后闹钟/日历生效；拒绝不写入（Android 13+ 通知权限；精确闹钟权限）
- [ ] ④ 发送失败时能 failover 到已保存的 ③（若已配）
- [ ] 回桌面后通知「保持连接」仍在；再进 App 不必重配即可聊（划掉多任务除外）

### 语音

- [ ] 未就绪时通知是「准备/下载…」，不是假「正在听」
- [ ] 聊天顶「停止听」或设置里能关掉后台监听；通知栏「停止」也行
- [ ] 下载 ASR/本地模型时能看到大小、进度、速度
- [ ] 聊天页内开着监听时直接说指令，不必先喊唤醒词；退到后台才要喊词
- [ ] 可自定义唤醒词；「开机恢复监听」开关（机型需自启白名单）

## 踩坑速查

| 现象 | 原因 | 处理 |
|------|------|------|
| 添加 Agent 闪回聊天 | 旧版 ViewModel 残留 completedProfile | ≥本次修复：sessionKey + 进页重置 |
| `10.0.2.2` 真机不通 | 仅模拟器 | 改电脑局域网 IP |
| 通知一直「正在听」却无反应 | 模型还在下 / 引擎未起 | 看进度；点「停止听」；设置关后台监听 |
| HTTP 多轮失忆 | 未用 Hermes Session 且旧版不带历史 | HTTP 兼容现带短历史；Hermes 靠 Session-Id |
| 签名冲突 | debug/release 证书不同 | 先卸载 |
| 网关下了模型仍不走本地 | 旧版写死 270M / API 名当权重 id | ≥0.1.13：`localModelId` + 资源库选用 |
| 网关气泡先弱文案再叠一段 API | 自动 escalate 时本地已 emit | ≥本次：自动模式先缓冲再决定 |
| HTTP 断线后回复重复一截 | 吐字后仍重试整段流 | ≥本次：已吐字不重试 |
| 确认闹钟显示成功但不响 | 无通知/精确闹钟权限却假成功 | ≥本次：缺权限明确失败并引导设置 |
| 一退出 App 连接就断 | 连接绑在 Activity ViewModel，onCleared 关 socket | ≥本次：Application 会话 + 保活通知 |
| 发送后输入框转圈不能打字 | 忙碌态锁死 Composer | ≥本次：思考在机器人气泡，输入框可继续打字 |
| 顶栏挂一整段回复占空间 | 语音 Status 塞了回复摘要且不消失 | ≥本次：短状态 + 单行 + 自动消失 |
| 新建对话后旧聊找不到 | 旧版整表清空 messages | ≥本次：多会话 Room；历史列表回看 |
| 配置助手不认裸 Key | 只认 sk-/带「Key:」标签 | ≥本次：整段粘贴密钥可识别 |
| 本地模型下载中断重来 / 不能暂停 | 每次删 `.part`、无 Range | ≥本次：暂停保留断点，可继续 |
| 主题只改气泡不改背景 | Atmosphere 未接 theme | ≥本次：主题渐变 + 可图片背景 |
