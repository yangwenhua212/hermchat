## 检查清单（随手勾）

### 安装与配置

- [ ] Release APK 能装上（同签名覆盖；debug→release 先卸）
- [ ] **添加 Agent** 能进配置助手，不会闪回聊天
- [ ] 「连电脑上的助手」或手填 `ws://` 能测连进聊天
- [ ] **端侧网关**：配 DeepSeek +（可选）下载本地模型；短句走本地、长问走 API；改闹钟出确认卡
- [ ] **本地优先解析（实验）**：设置开开关前有知情弹窗；复杂指令失败时顶栏「已改用云端」并仍能出确认卡；续跑走 API
- [ ] **识图（一期）**：Composer 选图；用支持 vision 的 ②/④/Hermes/WS 问「图里写了什么」；本地顶栏短提示不看图
- [ ] **附件（二期+三期）**：发 txt/md 能被模型引用；PDF 在 vision 通道按首页图理解；系统分享入草稿/附件；气泡图可点大图；③ Bridge 带图
- [ ] **首包超时**：云端 12s 无回复时顶栏「改用本地…」或「改用备用…」（④ 有本地模型时）
- [ ] **本地记忆**：④「请记住…」确认写入；换会话能召回
- [ ] **联网搜索**：不填 key 问资料能回摘要（SearXNG/DDG）；填博查或 Tavily 后优先走对应源；失败可落到备用源；不弹浏览器
- [ ] **拒违法**：说「教我电信诈骗」等应直接拒绝并说明原因，不出工具确认卡
- [ ] 纯 HTTP 兼容：只聊天、无本机工具确认（②）
- [ ] **资源库**：设置 / Agent 下拉可进；能看到模型目录路径；已装可删、可「选用到当前」；下载中离开资源库页应继续，暂停仍有效
- [ ] 本地 / 网关配置页可选目录中的模型（网关 API 名与本地兜底分开）

### 对话与工具（主线 ③）

- [ ] 流式回复跟手；「新建对话」能救慢会话；历史列表能回看旧聊且不丢；换 Agent 后历史只见该 Agent 的会话
- [ ] 助手气泡喇叭可朗读；设置「自动朗读」时边出字边读且读完（不中途掐）；只读本轮刚生成一次（离开再进不重读）；系统朗读有声
- [ ] 本机工具确认后闹钟/日历生效；拒绝不写入（Android 13+ 通知权限；精确闹钟权限）
- [ ] **打开应用 / 拨号 / 地图 / 邮件**：④「打开抖音」「打开设置」「拨打 10086」「地图搜星巴克」「发邮件给 a@b.com」；「打开抖音官网」才开网页
- [ ] **Loop 阶段**：多步任务气泡侧可见「分析中 / 执行中 / 观察中」
- [ ] ④ 发送失败时能 failover 到已保存的 ③（若已配）
- [ ] 回桌面后通知「保持连接」仍在；再进 App 不必重配即可聊（划掉多任务除外）

### 语音

- [ ] 未就绪时通知是「准备/下载…」，不是假「正在听」
- [ ] 聊天顶「停止听」或设置里能关掉后台监听；通知栏「停止」也行
- [ ] 下载 ASR/本地模型时能看到大小、进度、速度
- [ ] 聊天页内开着监听时直接说指令，不必先喊唤醒词；退到后台才要喊词
- [ ] 可自定义唤醒词；「开机恢复监听」开关（机型需自启白名单）
