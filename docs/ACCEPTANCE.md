# 真机验收清单（约 10 分钟）

对照 [PRODUCT.md](PRODUCT.md) 成功标准：安装后不看企业后台文档，完成「配置 → 对话 →（可选）工具确认」。

环境：Android 8+ 真机（或模拟器）；电脑与手机同一 Wi‑Fi（模拟器用 `10.0.2.2`）；Agent 端点已在本机监听。

## A. 安装

- [ ] 安装 Debug / Release APK（见 [RELEASE.md](RELEASE.md)）
- [ ] 首次打开进入三步配置，而非空白崩溃

## B. 配置（目标 ≤ 5 分钟）

- [ ] **手填**：选类型 → 填地址 →「测试」成功 → 起名 → 进聊天
- [ ] **自动探测**：点「自动探测」能列出至少一处可达端点（Agent 已开机时）
- [ ] **扫码或粘贴**：用 [SETUP_QR.md](SETUP_QR.md) 生成配置，手机扫码/粘贴后地址与名称正确
- [ ] 测连失败时「跳过测连」仍能进入聊天

## C. 对话

- [ ] 发送文字，出现用户气泡并入库（杀进程重进仍在）
- [ ] Agent 在线时流式回复可见；断线时有未连接提示
- [ ] 顶栏可切换 / 添加第二个 Agent

## D. 快捷指令与输入偏好

- [ ] 快捷指令可插入或发送；长按可改顺序
- [ ] 顶栏「调音」可切换语音优先 / 文字优先 / 混合，返回聊天后布局符合预期

## E. 工具与语音（可选但建议）

- [ ] 发送「明天下午3点提醒我开会」→ 出现确认卡 → 允许后写入系统日历
- [ ] 拒绝确认卡不写入
- [ ] 麦克风按住/点击可 ASR；开启唤醒后喊预设词有反馈（国产 ROM 需白名单时记录说明）

## F. 已知可接受限制（不必挡发布）

- 系统 `SpeechRecognizer` 依赖厂商离线包，不稳定不算阻断
- 自动探测仅覆盖常见端口与网关，非常规端口需手填
- Release 未配置正式签名时可能使用 debug 签名（仅内测）
