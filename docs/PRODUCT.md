# HermChat / HxSync — 产品说明

## 一句话

个人用户的 **AI Agent 口袋客户端**：在 App 里像搭积木一样连上自己的 Agent，界面完全听用户的——不是企业 IM 的附属机器人。

## 不是什么 / 是什么

| 不是 | 是 |
|------|----|
| 又一个企业协作套件 | 以 Agent 为核心的手机客户端 |
| 要用户去网页配回调、白名单 | 配置全在 App 内完成 |
| 千人一面的固定聊天壳 | 快捷指令、主题、输入方式可定制 |
| 只服务一家 Agent | Hermes / OpenClaw / 自定义端点，可多开切换 |

## 相对飞书的机会

飞书「乱」不是偶然：它服务企业权限与合规，入口与审批天然重。个人 / 极客只想把家里或云上的 Hermes、OpenClaw 装进手机时，就会撞上：

- 入口藏在工作台 → 应用管理 → 机器人 → 开发者后台  
- IP 白名单、事件订阅、权限申请、消息回调一步错全废  
- AI 是附加能力，主力仍是企业 IM  
- 气泡、按钮、交互用户改不了  

HermChat 反向设计：**简单配置 + 界面归属用户**。

## 配置：三步，目标五分钟

1. **选 Agent 类型** — Hermes / OpenClaw / 自定义  
2. **填地址** — 一行 WebSocket / HTTP，带「测试」按钮  
3. **起名字（可选）** — 如「我的小龙虾」  

成功即进聊天。用户不需要知道白名单或回调。

### 预设与扫码（进阶）

| 类型 | 预设方向 |
|------|----------|
| Hermes（本地） | 常见本地地址，可自动探测 |
| Hermes（云端） | 扫码登录类流程（后置） |
| OpenClaw | 本地 HTTP 预设，可自动探测 |

电脑跑 Agent 时终端出二维码 → 手机一扫填好配置（后置）。

## 聊天页：用户说了算

| 可定制 | 说明 |
|--------|------|
| 快捷指令栏 | 拖拽 / 长按排序（短信、日程等，权限与确认另议） |
| 气泡样式 | 颜色、圆角、字体 |
| 默认输入 | 语音优先 / 文字优先 / 混合 |
| Agent 头像 | 图片或 emoji |
| 主动推送 | 哪些事允许 Agent 主动提醒 |

MVP 先保证能聊、能连、能执行；定制项按优先级后置，但信息架构预留，避免做成「又一个固定壳」。

## 多 Agent：像切账号

顶栏展示当前 Agent，下拉切换已保存配置；「添加新 Agent」走同一套三步流程。切换不重装、不进后台网页。

## MVP 边界（保持专注）

**先做稳：**

- App 内连接至少一种 Bridge（Hermes）  
- 文字流式 + 本地消息存储  
- 唤醒 + ASR（可降级预设词）  
- 工具执行 + 用户确认（如日历）  

**刻意后置：**

- 复杂 Skill Store、多 Agent 协作编排  
- 屏幕 GUI 自动化、iOS  
- 云端账号体系、群聊  
- 完整主题商店（先做有限自定义）  

## 成功标准（产品语言）

一个干净的 APK：任何人下载安装后，**约 10 分钟内**完成「选类型 → 填地址 → 测连 → 对话 →（可选）确认执行工具」，且全程不必打开企业后台或开发者文档。
