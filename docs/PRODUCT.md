# HermChat / HxSync — 产品说明

## 一句话

**HxSync** 是通用的个人 AI Agent **口袋客户端**：Agent 可跑在云端/电脑，也可（分阶段）跑在手机内；协议兼容常见运行时（含 Hermes 一类），**不绑死单一品牌**。界面听用户的——不是企业 IM 的附属机器人。

品牌表述（B）：**通用口袋客户端 + 可选移动端运行时**；优先兼容开放协议，而非「某某官方 App」排他绑定。

## 三种模式（对等，按需切换）

顶栏切换已保存配置，像换账号一样。

| 模式 | 本质 | 适用场景 | 配置方式 | 阶段 |
|------|------|----------|----------|------|
| **远程 Agent** | 手机经 WebSocket 连接已在电脑/云端运行的 Agent | 强算力、已有桌面/云端环境 | 填地址或扫码 | **Phase A（已交付主干）** |
| **直连 API** | 不经完整 Agent 运行时，App 直接调 OpenAI 兼容 HTTP | 要最强云端模型、接受按量付费 | 填 Base URL + API Key + 模型名 | **Phase A（已交付主干）** |
| **本地运行时** | Agent/推理在手机内（可接本地开源模型或再转 API） | 隐私优先、弱网/离线、自主可控 | 选模型下载或填 Key（规划中） | **Phase B（后置）** |

```
                 ┌──────────────────────┐
                 │     HxSync 手机       │
                 │  统一对话 / 工具确认   │
                 └──────────┬───────────┘
                            │
       ┌────────────────────┼────────────────────┐
       ▼                    ▼                    ▼
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ 远程 Agent    │   │ 直连 API      │   │ 本地运行时    │
│ WebSocket     │   │ OpenAI 兼容   │   │ 手机内推理    │
│ Phase A ✅    │   │ Phase A ✅    │   │ Phase B 🚧   │
└──────────────┘   └──────────────┘   └──────────────┘
```

| | 远程 Agent | 直连 API | 本地运行时 |
|--|-----------|----------|------------|
| 是否需要网络 | 需要（到电脑/云） | 需要（到服务商） | 可不需要（纯本地模型时） |
| 算力 | 电脑 / 云 GPU | 服务商 | 手机 CPU/NPU |
| 数据去向 | 自建端点 | API 服务商 | 默认可留在本机 |
| 本机工具（日历/闹钟等） | ✅ | ✅（客户端侧） | ✅（规划） |
| 成本 | 自建算力 | 按 API 付费 | 模型下载；推理免费 |

场景举例：在家连电脑大模型 → 远程；出门弱网 → 本地运行时（Phase B）；只要最强模型 → 直连 API；隐私优先 → 本地模型。

## EraHerm 分工

| 组件 | 隐喻 | 职责 |
|------|------|------|
| [eraherm-memory](https://github.com/yangwenhua212/eraherm-memory) | **记忆增强** | 可嵌入记忆内核；挂到兼容 Host |
| **hermchat / HxSync** | **口袋客户端** | 统一界面：连接远程 / 直连 API；Phase B 再承载可选移动端运行时；唤醒与本机工具 |

一句话：**memory 增强「记得」；HxSync 提供「同一 App 里对话」，Agent 在哪跑由用户选。**  
协议面向 WebSocket / OpenAI 兼容 HTTP 等，**兼容 Hermes 等实现，但不排他绑定。**

## 不是什么 / 是什么

| 不是 | 是 |
|------|----|
| 又一个企业协作套件 | 以个人 Agent 为核心的手机客户端 |
| 要用户去网页配回调、白名单 | 配置全在 App 内完成 |
| 千人一面的固定聊天壳 | 快捷指令、主题、输入方式可定制 |
| 只服务某一家 Agent 品牌 | 多端点、多模式、可多开切换 |
| Phase A 就在手机里塞完整桌面 Agent | 先连得上、聊得动；本地运行时分阶段 |
| 在 App 里重做完整记忆内核 | 记忆交给 eraherm-memory（或其它记忆层） |

## 相对飞书的机会

飞书服务企业权限与合规，入口重。个人只想把**自己的 Agent** 装进手机时，会撞上开发者后台、白名单、回调。

HxSync 反向设计：**简单配置 + 界面归属用户 + 三种部署对等可选。**

## 配置体验

### Phase A（当前）

1. 选类型：远程 WebSocket │ 直连 HTTP │ 自定义  
2. 填地址（可测连 / 探测 / 扫码）；HTTP 可填 API Key、模型名  
3. 起名字（可选）→ 聊天  

详见 [CONNECT_AGENTS.md](CONNECT_AGENTS.md)、[BRIDGE_PROTOCOL.md](BRIDGE_PROTOCOL.md)、[SETUP_QR.md](SETUP_QR.md)。

### Phase B（规划）

本地运行时选型、模型下载与更新：见 [LOCAL_MODEL.md](LOCAL_MODEL.md)。

## 聊天页：用户说了算

快捷指令、气泡主题、输入偏好、多 Agent 顶栏切换——信息架构已有；更深定制持续迭代。

**界面文案规范**：主界面保持干净，不堆说明小字 / 备注；细则见 [UI.md](UI.md)。

## 分阶段边界

**Phase A — 已做稳 / 继续打磨**

- 远程 Agent（WebSocket）+ 直连 API（HTTP 兼容）  
- 流式对话、本地消息、多 Agent 切换  
- 本机工具（日历、闹钟）+ 确认卡  
- 唤醒（系统 ASR；离线 sherpa 另排期）  

**Phase B — 后置**

- 手机内可选 Agent / 本地模型运行时（llama.cpp 等）  
- 复杂 Skill Store、多 Agent 编排、GUI 自动化、iOS、云账号体系  
- 完整主题商店；App 内嵌完整记忆内核  

## 成功标准

任何人安装 APK 后，约 10 分钟内完成「选模式 → 配好 → 对话 →（可选）确认执行本机工具」，不必打开企业后台。Phase B 另定「下载小模型后离线对话」标准。
