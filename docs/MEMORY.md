# 本地记忆（④ Agent loop 极简）

本机 Room 存事实 + **关键词召回**，给端侧网关 Loop 用。  
**不是** [eraherm-memory](https://github.com/yangwenhua212/eraherm-memory)（向量/图谱/HTTP 内核仍留给远端 Host）。

## 能力

| 工具 | 风险 | 说明 |
|------|------|------|
| `memory.recall` | 只读，可静默 | 关键词/子串打分召回 |
| `memory.remember` | 写，须确认 | 写入本机；同文去重更新 |

默认开启。④ 首轮会用当前用户话做短召回，注入「【相关记忆】」（无命中则跳过）。

端侧话术：「请记住…」→ remember；「还记得… / 回忆一下…」→ recall。

上限约 200 条；超限删最旧未钉死项；单条 ≤500 字。

## 怎么用

1. 设置 → **端侧网关** →「本地记忆」开（默认开）
2. 用 **端侧网关** 对话：「请记住我喜欢绿茶」→ 确认 → 写入
3. 换会话再问「我喜欢什么」→ 可召回或自动注入

数据只在本机；换机/清数据会丢。

## 不做

- 向量嵌入、图谱、反馈闭环（那是 eraherm-memory）
- 把 Python 记忆服务打进 APK
- 替代 ③ Hermes 侧长记忆
